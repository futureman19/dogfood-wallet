Dogfood Wallet
GitHub Docs

A wallet your agent can spend from.

The model asks. A signer on your machine authorizes. The key never leaves disk. Open source BSV vault — not a hosted wallet, not a business.

Clone the repo Read the README

01 — Intent

The agent emits a payment request. It never sees a WIF. Tools: balance, send, kill, x402.

02 — Policy

Sat caps, allowlist, killfile. Empty allowlist is fail-closed. Sweep is human-only.

03 — Settlement

BSV mainnet. Tiny fees. MCP for any agent runtime. Signer stays on this computer.

MIT. TypeScript / Bun. Caps in sats, not USD.
Not custody. Not a consumer portfolio app. Not Coinbase x402.
